01 · What is a Linear Model?
📈

Linear Model DefinedA relationship where y changes at a constant rate

Standard Form
y = mx + b
m = slope (rate of change)  |  b = y-intercept (initial value)
  • ▶Constant rate of change — same Δy for every unit Δx
  • ▶Graph is always a straight line
  • ▶SAT word problem → "per", "each", "every" → that's the slope
🗃

Reading a Table of ValuesIdentify slope & equation from any table

Sample Table

STEP 1 — Find Slope
m = Δy/Δx = 4/1 = 4
Check: Δy is constant (+4 each row)
STEP 2 — Find y-intercept
At x=0, y = 3 → b = 3
Read directly from x=0 row
RESULT — Equation
y = 4x + 3
  • ▶Verify linearity: Δy must be constant across all rows (constant Δx)
  • ▶If x=0 is in the table, b is the y-value directly — no calculation needed
  • ▶If x=0 is NOT in the table: use b = y − mx with any (x, y) row
📖

Interpreting in ContextWhat slope & y-intercept really mean

Slope (m) = Rate of Change
m = change in y per unit of x
Units: (y-units) per (x-unit). Represents speed, cost-per-item, growth rate, etc.
Y-intercept (b) = Initial / Starting Value
b = value of y when x = 0
Represents initial amount, starting cost, y-value at time zero, etc.
Real Context Example
"A taxi charges $3 base fare + $2.50 per mile"
→ Equation: y = 2.50x + 3
→ Slope (2.50) = $2.50 per mile (cost per mile)
→ y-intercept (3) = $3 base fare (cost at 0 miles)
  • ▶SAT question: "What does the slope represent?" → look for rate/per/each
  • ▶SAT question: "What does the y-intercept represent?" → starting/initial value

Making Predictions with DesmosInterpolation & Extrapolation

After running regression
Type x = [value] in new expression
Desmos draws a vertical line at that x — hover or click to read the y-value on the regression line
📍 Interpolation
Predicting within the range of your data. More reliable. Example: data goes from x=0 to x=10; predict at x=5.
y = 4(5) + 3 = 23
🚀 Extrapolation
Predicting beyond the range of your data. Less reliable. Example: data goes to x=10; predict at x=20.
y = 4(20) + 3 = 83
Desmos Shortcut to Predict
Method A
Type y = 4x + 3 → substitute x manually → read y
Method B
After regression → type x = 7 → trace intersection with regression line
Method C
Add a column to your table — type x-value, leave y₁ blank — Desmos fills it in!
  • ▶R² value (shown after regression): closer to 1.00 = better linear fit
  • ▶R² = 1.00 → data is perfectly linear (all points on one line)

8 SAT Question Types DecodedHow to tackle each type with Desmos

SAT Question TypeWhat it's really askingDesmos Strategy
"What is the slope / rate of change?" Find Δy/Δx from the table Run y₁ ~ mx₁+b → read m directly
"What is the y-intercept / initial value?" Find y when x = 0 Run regression → read b value; or look at x=0 row
"Which equation models this data?" Find equation from table values Enter table → run regression → match to answer choices
"Predict y when x = [value]?" Substitute x into the model equation After regression, type x=[value] → hover on line
"What does the slope represent in context?" Interpret rate of change in real-world units Find m → attach units from problem ($/mile, °/hr, etc.)
"Find x when y = [value]?" Reverse-solve the linear equation Type y=[value] as new line → intersection with regression
"How does y change if x increases by 3?" Multiply slope by the change in x m × 3 = change in y. Verify: pick two rows 3 apart in table
"Is the relationship linear?" Check if differences are constant Enter data → R² ≈ 1.00 confirms linear; if not, data is non-linear

Is the Table Linear?Use R² to confirm linearity

R² (R-Squared)
R² = 1.00 → perfect linear fit
Shown after running regression. Closer to 1 = more linear. SAT data is usually close to 1.
✅
R² = 1.00: Data is exactly linear — model is perfect
⚠️
R² ≈ 0.95: Strong linear trend — model is approximately linear
❌
R² ≈ 0.60: Weak linear fit — may be non-linear data
  • ▶Manual check: Is Δy constant across equal Δx steps? If yes → linear

05 · Scatter Plots, Line of Best Fit & Residuals
⠿

Scatter Plot & Line of Best FitApproximately linear real-world data

  • ▶Line of best fit minimizes total residual distance (least squares)
  • ▶Not all points need to be ON the line — line passes through the middle
  • ▶Desmos draws this line automatically after y₁ ~ mx₁ + b
↕

Residuals ExplainedDistance from data point to the model line

Residual Formula
residual = y_actual − y_predicted
Positive residual → point is above the line. Negative → point is below the line.
Worked Example
Model: y = 2x + 5
At x = 4: predicted y = 2(4)+5 = 13
Actual data point: (4, 15)
Residual = 15 − 13 = +2 (point is above the line)
  • ▶Residual = 0 means the point lies exactly on the best-fit line
  • ▶SAT asks: "Which point has the largest residual?" → furthest from line
  • ▶Desmos: run regression → open residual table from the parameters area
⚠️

SAT Traps & Power TipsLinear models & Desmos

⚠ TRAP 1: Confusing slope with y-intercept in context
"Initial fee" = y-intercept (not slope). "Per hour" = slope (not y-intercept). The words tell you which is which — read carefully.
⚠ TRAP 2: Assuming x=0 is in the table
If the table starts at x=2, you can't just read b. Use b = y − mx with any table row. Or let Desmos regression find b.
⚠ TRAP 3: Using Δy only (not Δy/Δx) for slope
When Δx ≠ 1, slope = Δy ÷ Δx, NOT just Δy. A table with x-steps of 2 means each Δy represents 2 units of x.
✓ TIP: Always run Desmos regression first
For any table question, enter data → y₁ ~ mx₁ + b → read m and b. Takes 20 seconds and eliminates all calculation errors.
✓ TIP: Check your answer by plugging back into the table
After finding the equation, verify 2–3 rows from the table match the equation. Desmos makes this instant.
🖥 DESMOS SPEED TIP
Add a 3rd column to your Desmos table labeled y₁ = mx₁ + b (after regression). It shows predicted y for every x — instantly compare actual vs. predicted values!
