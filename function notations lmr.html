Notation: f(x) = output when input is x

01 · What is a Function?
ƒ

Function DefinitionA rule: each input → exactly one output

INPUT x

OUTPUT f(x)

Key Rule
One input → Exactly one output
If any input maps to two or more outputs, it is NOT a function
  • ▶f(x) is read "f of x" — it means the output of function f at input x
  • ▶Other names: g(x), h(x), p(t) — letter choice doesn't matter
  • ▶SAT: f(3) = 7 means when x=3, output = 7. It does NOT mean f×3
✓✗

Function vs. Not a FunctionVertical Line Test & mapping rules

✓ IS a Function
Each input maps to exactly one output. Two inputs CAN share an output.
✗ NOT a Function
One input maps to two outputs → breaks the function rule.
Vertical Line Test (for graphs)
Draw a vertical line through the graph.
Hits 1 point → function ✓
Hits 2+ points → not a function ✗
⟷

Domain & RangeThe allowed inputs and possible outputs

Domain
All valid x-inputs
The set of all x-values you can plug in. Restrictions come from: ÷0 or √negative
Range
All possible y-outputs
The set of all f(x) values the function can produce. Look at graph's y-coverage.
Domain Restriction Rules
÷ 0
Denominator ≠ 0 → set denom ≠ 0 and exclude those x-values
√
Square root → expression inside ≥ 0
log
Log/ln → argument must be > 0
poly
Polynomials → domain is all real numbers (−∞, ∞)
Example: f(x) = √(x − 3)
Domain: x − 3 ≥ 0 → x ≥ 3 or [3, ∞)
Range: √ always ≥ 0 → y ≥ 0 or [0, ∞)
02 · Function Notation & Evaluating Functions
f(x)

Anatomy of f(x) NotationEvery part has a specific meaning

Reading f(x) Expressions
f(3) → evaluate at x = 3  |  f(a) → evaluate at x = a
f(2x) → replace every x with 2x  |  f(x+1) → replace x with (x+1)
  • ▶f(x) = 3 means the output is 3 — the y-value is 3
  • ▶SAT trap: f(3) means "evaluate f when x=3" — NOT "f times 3"
  • ▶f(0) = y-intercept. This is tested often!
✏

Evaluating Functions — 4 TypesSubstitute every x with the given expression

TYPE 1
Evaluate at a number: f(3)
f(x) = 2x² − x + 4
f(3) = 2(3)² − (3) + 4 = 18 − 3 + 4 = 19
TYPE 2
Evaluate at an expression: f(a+1)
f(x) = 3x − 2
f(a+1) = 3(a+1) − 2 = 3a + 3 − 2 = 3a + 1
TYPE 3
Evaluate from a table: find f(2)

Read directly from row x=2
TYPE 4
Evaluate from a graph: find f(2)
At x=2, trace up to graph curve, then left to y-axis. That y-value is f(2).
⚡

SAT Notation TricksThe patterns that appear most on SAT

Pattern A — Nested Evaluation
f(x)=x+2, g(x)=3x
f(g(2)) → first: g(2)=6 → then: f(6)=8 ✓
g(f(2)) → first: f(2)=4 → then: g(4)=12
Pattern B — Find x given f(x)
f(x) = 2x + 3, find x if f(x) = 11
Set 2x + 3 = 11 → 2x = 8 → x = 4 ✓
Pattern C — f(x) in terms of another
If f(x+2) = 3x − 1, find f(5):
x+2 = 5 → x = 3 → f(5) = 3(3)−1 = 8 ✓
  • ▶For f(x+2): set the inside equal to the target, solve for x, then substitute
  • ▶SAT often gives you f(some expression) and asks for f(a number) — work backwards
03 · Key Function Types for SAT
Linear
f(x) = mx + b
Constant rate of change. Straight line. Domain & Range: all reals.
Quadratic
f(x) = ax² + bx + c
Parabola. Has vertex, axis of symmetry. Range: [min, ∞) or (−∞, max]
Absolute Value
f(x) = |x|
V-shape. Always ≥ 0. Range: [0, ∞). Left side mirrors right.
Exponential
f(x) = a · bˣ
Growth (b>1) or decay (0<b<1). Range: (0, ∞). Horizontal asymptote at y=0.
Piecewise
f(x) = {rule1 if x<a
rule2 if x≥a}
Different formulas for different x-intervals. Open circle = excluded.

Composite Functions f(g(x))Apply one function inside another — ORDER matters!

Definition
(f ∘ g)(x) = f(g(x))
Apply g first, then apply f to the result. Also written as f(g(x)).
Process Flow: f(g(x))

Worked: f(g(3))
f(x) = x + 1
g(x) = x²
g(3) = 9
f(g(3)) = f(9) = 10
Worked: f(g(x)) general
f(x) = 2x − 1
g(x) = x + 3
f(g(x)) = f(x+3)
= 2(x+3) − 1 = 2x+5
⚠ f(g(x)) ≠ g(f(x)) — ORDER MATTERS!
Composition is NOT commutative. Always apply the innermost function first. SAT will test both orders and only one will give the right answer.
f⁻¹

Inverse Functions f⁻¹(x)Swap input & output — reverse the machine

Key Relationship
f⁻¹(f(x)) = x
If f(a) = b, then f⁻¹(b) = a. The inverse undoes the function.
x
→
f(x)
←
f⁻¹(x)
y
Steps to Find Inverse
1
Replace f(x) with y:  y = 2x + 6
2
Swap x and y:  x = 2y + 6
3
Solve for y:  y = (x − 6)/2
4
Write:  f⁻¹(x) = (x − 6)/2
✓ GRAPHICALLY
Inverse is the reflection of f over the line y = x. If (a,b) is on f, then (b,a) is on f⁻¹.
⚠ f⁻¹(x) ≠ 1/f(x)
The −1 is NOT an exponent. f⁻¹(x) means "inverse function", not reciprocal!
05 · Function Transformations
↔↕

All Transformation RulesHow modifying f(x) shifts, flips & stretches the graph

SHIFT ↑
f(x) + k
Move graph UP by k units. y-intercept increases by k. All y-values + k.
SHIFT ↓
f(x) − k
Move graph DOWN by k units. y-intercept decreases by k. All y-values − k.
SHIFT →
f(x − h)
Move graph RIGHT by h units. Note: minus h inside → right. (Counterintuitive!)
SHIFT ←
f(x + h)
Move graph LEFT by h units. Plus h inside → left. (Counterintuitive!)
STRETCH ↕
a·f(x), a>1
Stretch graph vertically by factor a. Graph gets taller. All y-values × a.
COMPRESS ↕
a·f(x), 0<a<1
Compress graph vertically by factor a. Graph gets flatter. All y-values × a.
FLIP ↕
−f(x)
Reflect over the x-axis. All y-values negate. Graph flips upside-down.
FLIP ↔
f(−x)
Reflect over the y-axis. All x-values negate. Graph flips left-right.
✓ MEMORY TRICK: Inside vs. Outside
Outside f(x): affects y-values → vertical change (shift up/down, flip, stretch)
Inside f(x): affects x-values → horizontal change (shift left/right) — and direction is opposite to sign

06 · Even & Odd Functions · Piecewise · SAT Traps
±

Even & Odd FunctionsSymmetry properties tested on SAT

EVEN Function
f(−x) = f(x)
Symmetric about the y-axis. Left half mirrors right half.
Examples: x², |x|, cos(x)
ODD Function
f(−x) = −f(x)
Symmetric about the origin. Rotate 180° = same graph.
Examples: x³, x, sin(x)
Quick Test
Substitute −x into f(x). If result = f(x) → even. If result = −f(x) → odd. If neither → neither.
⎧

Piecewise FunctionsDifferent rules for different x-ranges

General Form
f(x) = ⎧ rule₁  if x < a
⎨ rule₂  if a ≤ x ≤ b
⎩ rule₃  if x > b
Worked Example
f(x) = ⎧ 2x + 1   if x < 0
⎩ x² − 3   if x ≥ 0
f(−2): use 2x+1 (x<0): 2(−2)+1 = −3
f(0): use x²−3 (x≥0): 0−3 = −3
f(3): use x²−3 (x≥0): 9−3 = 6
  • ▶Open circle (○) on graph = that endpoint is excluded
  • ▶Closed circle (●) = that endpoint is included
  • ▶SAT: identify which piece to use based on where x falls
⚠️

SAT Traps & Power TipsThe function mistakes that cost the most points

⚠ TRAP 1: f(x+a) ≠ f(x) + f(a)
Functions are NOT distributive. For f(x)=x², f(x+2) = (x+2)² = x²+4x+4, NOT x²+4.
⚠ TRAP 2: f(−x) shifts horizontally, not negates output
f(−x) reflects over y-axis; −f(x) reflects over x-axis. Two different operations!
⚠ TRAP 3: f(x−h) shifts RIGHT, not left
f(x−3) moves the graph right 3. The minus sign inside means right — counterintuitive! f(x+3) moves left 3.
✓ TIP: "Zeros" of a function = x-intercepts
Set f(x)=0 and solve. SAT may ask "for how many values does f(x)=0?" — count x-intercepts on the graph.
✓ TIP: f(a) = b means point (a, b) is on the graph
f(2)=5 tells you the graph passes through (2, 5). Use this to verify equations or find unknowns.
✓ TIP: Work composites from the inside out
For f(g(h(x))), evaluate h(x) first, then g, then f. Never skip steps — this is where careless errors happen.
07 · Master Summary — All Function Concepts at a Glance
Basics
  • ▶One input → one output
  • ▶VLT: vertical line hits once → function
  • ▶Domain: all valid x inputs
  • ▶Range: all possible y outputs
Notation
  • ▶f(a) → substitute x = a
  • ▶f(x+1) → replace x with (x+1)
  • ▶f(0) = y-intercept
  • ▶f(x)=0 → x-intercepts (zeros)
Composite & Inverse
  • ▶f(g(x)): apply g then f
  • ▶f(g(x)) ≠ g(f(x)) in general
  • ▶f⁻¹: swap x↔y, solve for y
  • ▶f⁻¹(f(x)) = x always
Transformations
  • ▶f(x)+k → up k
  • ▶f(x−h) → right h
  • ▶−f(x) → flip over x-axis
  • ▶a·f(x) → vertical stretch
Even / Odd
  • ▶Even: f(−x) = f(x), y-axis sym.
  • ▶Odd: f(−x) = −f(x), origin sym.
  • ▶Test: substitute −x, simplify
  • ▶Most functions are neither!
